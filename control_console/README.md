# MediaFlow 控制台

本目录是 MediaFlow 的本地产品界面。它只访问 `127.0.0.1:48138` 的本地控制接口，不直接连接手机。

## 功能页面

- `/`：任务台，负责内容、互动、规模、设备、预览和启动。
- `/run`：运行状态、队列控制和安全停止。
- `/records`：任务、纠错记录与互动凭证。
- `/devices`：设备健康、实时画面、初始化和档案。
- `/content`：内容计划、评论资产、预设和模型连接。
- `/content/guide`：主题、搜索词、评论模板、词池与发送前约束的填写规范。
- `/governance`：主题人工复核、覆盖缺口、证据盘点、保留政策和数据库备份。

## 本地开发

要求 Node.js `>=22.13.0`。在本目录执行：

```powershell
npm install
npm run dev
```

正式运行不需要单独启动本目录，根目录的 `MediaFlow.exe`、`启动-MediaFlow控制台.cmd` 或 `run-riskflow-console.ps1` 会统一管理网页和本地接口。

## 验证

```powershell
npm test
npm run lint
```

`npm test` 会先构建，再检查三个页面的服务端渲染、关键安全文案和接口入口。页面测试通过不代表设备在线；设备状态必须在控制台和 ADB 中实时确认。

## 设计约束

- 面向非技术测试人员，状态名称使用“等待执行、正在执行、已结束”。
- 亮暗主题共享同一套 Linear 风格设计变量。
- 密钥只提交给本地控制接口，界面不回显完整值。
- 证据页面只显示已登记或白名单路径内的图片，不暴露任意本机路径。
- 网页不能绕过队列直接触发 ADB 或设备动作。
