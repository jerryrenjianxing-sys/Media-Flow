## Tasks

### Task 1: 平台自动化 API 与技能客户端

抽取 `/api/automation` 接入，复用 AgentPlatform、AgentVirtualOperations、维修及更新服务。不依赖自建 sessions/turns；session_id 只关联。脚本完整覆盖状态、设备、计划、执行/恢复、进度、暂停/停止、证据、维护、记忆和更新。保留原 MCP 和旧接口作为兼容期，不在新路径使用。
请求携带持久化 request_id，返回业务 operation/plan id 与真实状态。计划提交重试只查原计划，读可有界重试，写不盲重放。隔离队列测试真实规划/提交/恢复/并发/故障/草稿不变，测试命令用主目录 Python 执行工作区 scripts/test-python.py。

### Task 2: 上游原生前端与同源网关

固定上游源码及锁文件、许可证、独立可重复构建；先原版再品牌覆盖。不 fork 引擎。原生 UI 路由与旧管理页在同一服务入口分流；同源代理支持 HTTP、SSE、WebSocket/PTTY，错误保留 HTTP 语义；资源离线可用。
原生用户存储及草稿恢复；?session= 兼容跳转。品牌、管理/停止入口、默认中文、开发面板收起；保持原生核心行为。

### Task 3: 原生运行与兼容迁移

原生配置使用直连千问 Token Plan，原生默认工具可用，无产品权限等级。取消新回合自建索引/补齐；凭证通过原生认证迁移，失败可重试且不影响空会话。迁移前数据库备份；当前会话 ID 保留、清理会话调用原生 archive；旧草稿一次迁入 native 存储，绝不发送。
引擎单实例、可恢复启动和真实连接测试；配置独立，原认证和业务视觉配置保留。对旧 API 实现兼容代理，保留历史业务回执。

### Task 4: 验收、审查与本机交付

原版/品牌同组会话、原生工具、无 Key、断连、重启、UI/主题/窄屏验收；API 客户端隔离任务端到端与修复夹具测试；真实模型<=10 且不操作设备。
OpenSpec strict、隔离 Python、旧/原生前端测试、lint、typecheck、build、凭证扫描、代码审查。通过后唯一提交合入本机，备份/空闲检查/安全切换及数据核对。不通过不切换，记录具体未完成。
