# RiskFlow 真机 Agent 辅助初始化指南

## 适用范围

本指南用于已经开启 USB 调试、完成 ADB 授权、屏幕已解锁、抖音已安装并登录的真机。开发者选项、首次 USB 授权、抖音安装与登录不属于 RiskFlow 初始化。

真机初始化不是无人值守流程。厂商安装确认、系统安全确认、登录或身份验证由用户在对应手机上完成；RiskFlow 在 `waiting_user` 断点继续。默认全程不点赞、不收藏、不评论。

## 交付标准

- 设备名称与 ADB 序列号一一对应，操作范围只包含当前指定设备。
- uiautomator2、截图、UI 树、滑动和中文输入均完成复验，结束时恢复原输入法。
- 主页、搜索、视频标签、搜索结果、搜索沉浸流、点赞、收藏、评论面板、评论输入入口与关闭入口均有固定程序证据。
- 设备、抖音版本、显示签名与 Adapter 版本写入同一份版本化档案。
- 3 条零写入冒烟测试完整通过后才标记交付；真实写入验收默认关闭。

## 标准步骤

1. **锁定设备**：从设备页核对友好名称、型号与 ADB 序列号；同一时刻不允许其他 Worker、MBH 或人工工具持有该设备。
2. **前置检查**：确认状态为 `device`、屏幕已解锁、抖音已登录且没有登录/身份验证弹窗。
3. **准备控制组件**：运行初始化。若手机出现安装或安全确认，RiskFlow 应进入“等待你操作”；用户处理后点击“继续人工步骤”。不得跳过或绕过系统确认。
   - OPPO/ColorOS 重启后可能重新禁止 ADB 切换输入法。若页面提示“输入组件已安装，但手机系统禁止 ADB 切换输入法”，无需重复安装；请在开发者选项重新开启对应的 USB 调试安全权限或关闭权限监控，再点击继续。
4. **只读页面校准**：依次复验主页壳层、搜索、视频标签、语义搜索结果卡和搜索沉浸流。点赞、收藏、评论只定位控件，不触发账号写入。
5. **评论入口复验**：允许点击评论面板和底部输入入口；只有出现编辑框、输入焦点或键盘后才记为通过。不得输入或发送评论。
6. **未知差异升级**：已有截图/UI 树足以判定时直接修固定规则。只有同一未知页面指纹重复出现且语义仍无法确定，才允许 MBH 做单设备只读探索。
7. **MBH 边界**：观察后只点击已确认的导航、返回、关闭或列表级聚合入口；不得打开具体私信会话，不得点赞、收藏、评论、关注或回复。候选路径连续三次一致后，再交给固定程序复验。
8. **保存档案**：固定程序复验全部必需能力后，保存“设备＋包名＋抖音版本＋显示签名＋Adapter 版本”档案；失败或等待状态不得覆盖旧的已验证档案。
9. **零写入冒烟**：运行 3 条视频，点赞/收藏/评论概率全部为 0、评论保持预览。要求有效视频计数真实、页面恢复完成、写入计数均为 0。

## 状态解释

- `已就绪`：校准和零写入验收已通过。
- `等待你操作`：厂商确认、登录、安全验证或一个明确人工断点；不是程序失败。
- `需要复验`：抖音版本、显示参数或 Adapter 版本变化，旧坐标兜底已禁用。
- `初始化失败`：固定程序在已支持条件下仍无法完成，必须保留截图、UI 树、阶段和错误，不得自动重放。
