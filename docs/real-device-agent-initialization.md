# 真机按需准备与开发带测

产品默认MuMu；真机在用户明确启用和选择后使用。先核对当前设备清单、ADB授权和锁；历史在线记录不能替代实时检查。

## 按任务准备

- ADB可用即可检查画面；没有抖音或未登录不阻断设备管理与参数准备。
- 浏览检查当前应用与导航；搜索/评论再检查控制组件及中文输入，实际写入测试文字并读回才算通过。
- 厂商安装确认、USB授权、登录及安全验证由用户在手机完成；重复检查复用已成功能力。
- 不要求整套初始化、3条自检或三次旧巡检才能选任务。保留的完整初始化入口只用于显式维护，不默认运行。
- 真机按其实际显示档案检查，不能套用MuMu分辨率。Root不是必须条件。
- 遇未知页面先留证，只有需要开发带测时才使用[MBH接入](mbh-development.md)，并与Worker共用设备锁。
- 点赞、收藏、评论默认零；本次明确的写入范围才执行，结果未知不重放。
