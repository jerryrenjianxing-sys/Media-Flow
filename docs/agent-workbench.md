# MediaFlow 内置助手 · dev.19

首页点“连接助手”，再打开“服务商与模型”。原生服务商保持原样，额外提供千问AI平台Token Plan。可引用已保存千问配置，也可输入新Key；保存不代表调用通过。原生登录文件仅本机保存，不额外加密、不随包分发。传统任务表单和设备页面仍然可用。

## 使用流程

1. 新建对话，先说“检查设备和任务状态”，助手读取实际平台回执。
2. 说明设备、数量、轮次、内容入口和巡检频率；缺少参数时集中追问。
3. 核对后端生成的计划卡片，确认后执行。默认零点赞、收藏、评论，不继承旧高概率草稿。
4. “停止对话及本次任务”停止新工具并请求本批安全停止，不强杀模拟器、不恢复无关旧任务。
5. 给出故障任务编号，助手读取现有证据；按要求可向当前模型发送该应用截图。缺少现场则明确不能确认。
6. 要求修复后，助手在候选工作区实际编辑和测试。查看差异与回执，通过后导出补丁，交唯一主仓库发布新版本；不偷偷修改运行程序。

## 遇到问题

- 引擎缺资源或启动超时：修复安装后重试，旧任务台仍可用。插件SDK已随包提供，不要求客户装npm或WSL。
- Key已保存：只证明保存；模型错误看套餐、权限、额度或网络提示，不要把Key放聊天。
- 千问故障保护：处理原因后展开“助手用量与模型故障恢复”重置；不会自动重试消息、切换线路或清空用量。
- 等待回答或确认：回答当前问题或核对卡片，不重复发送任务。
- 候选测试失败：保留输出和差异，修改后再测，未知结果不算成功。

本版为未签名实验性开发版，不承诺全入口接管。套餐额度以服务商工作台为准，未返回用量不代表免费。私人镜像、运行数据和Key均不在本次程序包内。
