# 0002 状态改变失败不自动重跑

- 状态：Accepted，dev.39后按动作与设备粒度解释
- 日期：2026-08-26

## 决定

可能已经产生点赞、收藏、评论而结果无法确认时，保留未知动作证据且不重放。dev.39后不再因此一概结束整轮或取消整批：对应互动能力按设备批次暂停，确认安全页面后其他已验证能力可继续；连续模型故障或设备故障保留检查点等待。旧终态不迁移、不从头重跑。误判为未知的缺陷单独修复，不能靠删除记录掩盖。

## 原因

自动重跑可能反向取消已经成功的动作，或产生重复评论等二次写入。失败留证比猜测结果更安全、可审计。

## 后果

恢复操作需要根据证据人工或通过后续变更判断，不能把所有失败简单改回等待。
