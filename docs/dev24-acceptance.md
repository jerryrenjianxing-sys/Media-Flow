## 真实模型验证（严格10次）

隔离引擎通过测试专用计数转发访问官方千问，全部10次请求返回200，之后停止新增请求。
产品配置本身仍直接使用官方 Token Plan 地址，不经过测试计数器或旧模型代理。

实际工具链：原生 Skill发现/加载 → 原生命令运行随附 Python 客户端 → 隔离平台状态；
原生结构化追问 → 答案回送 → 读取/编辑隔离代码夹具 → 命令测试输出通过。
没有只凭 HTTP 状态判定上述链条通过。计数账本与原生消息现场留在忽略的本地验收目录。

平台计划、提交、重复提交、响应丢失后的查询、原批次恢复和结果回执由隔离任务库测试覆盖。
本轮没有执行真实视频或互动任务，没有上传新设备截图，没有发送点赞、收藏或评论。
