# dev.29 独立 Agent 与平台

用户已确认：平台和 Agent 是两个独立运行单元，唯一业务连接是原生 Skill 调用本机 API。

1. 平台 UI 固定 3001，API 48138；不创建、关闭或迁移聊天引擎。旧聊天 HTTP 入口明确退出使用。
2. Agent 使用已校验的官方 OpenCode 可执行文件直接提供 3000 Web UI。独立进程登记、独立 Windows 计划任务、独立启停；不经过 native_console 网关或自编译聊天页面。
3. 保留原生数据目录、凭证、会话及 Skill。启动不归档、不复制聊天、不运行迁移；保留千问官方地址预设。
4. 自动化业务组合脱离 AgentService，复用现有任务/维护/修复模块，不增队列或权限层。
5. 先红灯测试，再实施、隔离验证及静态检查。切换前备份并确认暂停、0运行、4等待；不调用模型、操作虚拟机或执行历史任务。
6. 核对官方页面、设置、历史及本地 Skill；分别停止一侧验证另一侧存活。未完成的真实模型交互和关闭 Codex 验证明确报告。

本轮不打包、不推送、不更新远端。先恢复官方原版，不加品牌补丁。官方网页的网络资源依赖如实记录，不将其声明为离线安装版。
