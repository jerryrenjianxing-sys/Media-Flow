# RiskFlow 社媒风控实验台

RiskFlow 是一套运行在本机的 Android 自动化测试系统，用于在已授权的测试设备上配置固定流程、并发执行、观察异常、保存证据并复核主题判断。

## 直接使用

1. 首次使用双击 `安装-RiskFlow.cmd`；它会安装独立环境、注册当前用户后台任务并创建桌面快捷方式。
2. 连接测试手机并开启 USB 调试。
3. 双击桌面的 RiskFlow 或根目录的 `RiskFlow.exe`；默认会打开 Windows 桌面窗口。
4. 需要开发或排障时，也可在浏览器打开 `http://127.0.0.1:3000/`，两种入口使用同一页面和同一份数据。
5. 在“设备”区点击“检索所有可用设备”，只选择状态为“ADB 在线”的设备。
6. 新真机在“设备”页打开“Agent初始化指南”，按序列号核对、人工断点、只读校准和 3 条零写入冒烟完成辅助初始化；Root 虚拟机可开启固定程序自动接入。
7. 初始化默认无写入；“完整写入验收”会真实发送 1 条固定测试评论，只有本次明确勾选时才会启用。
8. 先保持“仅预览评论”，从少量视频和单设备开始。

RiskFlow 由 Windows 当前用户计划任务独立托管，关闭 Codex 或启动窗口不会关闭后台。停机时双击 `停止-RiskFlow控制台.cmd`；如果仍有任务运行，系统会拒绝强制停机，应先在页面请求安全停止。`卸载-RiskFlow后台.cmd` 只移除后台自启动和快捷方式，不删除数据库、截图、日志或密钥。

需要在另一台 Windows 电脑安装时，运行 `packaging/out/Releases/RiskFlow.Internal-win-Setup.exe`。安装包已包含运行环境，不需要 Codex、Python、Node 或单独安装 ADB；首次使用仍需在本机页面配置 OpenRouter Key、连接并检索已授权设备。当前构建未做商业代码签名，仅适合内部测试分发。

## 页面入口

- **策略控制台**：设置主题模式、互动概率、视频数量、设备和预设。
- **设备画面**：真机继续每 5 秒刷新截图；已接入的 MuMu 可看实时画面，空闲时可人工接管，并可完成初始化、快速复验和报告查看。
- **运行记录**：查看全部任务、耗时、终态、纠错记录和评论证据。
- **评测与证据**：人工确认主题样本、查看正式一致率口径、盘点证据和创建本地备份。

## 当前安全边界

- 固定执行器是唯一能操作设备的组件；AI 只返回主题、安全或纠错建议，不直接点击手机。
- 每台设备由一个 Worker 独占，避免两条控制链同时操作。
- MuMu 实时画面的只读会话可与任务并存；人工接管必须先取得同一设备锁，不能抢占 Worker 或初始化。
- 实时串流只监听本机，网页拿不到 Shell、任意 ADB 或 Root 入口；串流失败自动退回截图。
- 结果不明的状态改变不自动重试，防止重复评论或反向取消点赞。
- 不安全或不确定内容会失败关闭，不进入互动概率判断。
- 评论默认预览；证据治理不会自动删除任何文件。
- 运行数据库、截图、日志和加密密钥均保存在本机，不进入 Git。
