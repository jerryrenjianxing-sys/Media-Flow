# dev.34 首页消息提醒检查

## 实现范围

新计划默认采用 `home_badge`：确认首页、截图、只观察消息按钮角标，不进入消息页、会话或主页。正常状态只有有消息/无消息，检查失败独立表示未确认，不算无消息。清晰数字附带原文和精确数；99+保留为99+而不是精确99；纯红点和数字不清只记录有消息。

旧配置缺少模式字段继续解释为legacy，旧任务及历史不改写。任务台高级设置保留旧版详细巡检。按永久虚拟设备ID保存提醒周期，持续存在只更新证据，平台确认不代表抖音已读；unknown保留前态，确认角标消失后再次出现才产生新提醒。新版准备不依赖v3校准、访客提醒或输入法。
