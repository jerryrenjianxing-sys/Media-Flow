# model-runtime-resilience Specification

## Purpose
为 RiskFlow 的云端多模态判断建立可审计、可熔断、可回放的运行契约，使供应商拒绝、瞬时网络故障和无效输出不会被误判为手机页面异常，也不会在长任务中形成无上限重复调用。

## Requirements

### Requirement: 模型故障必须结构化分类
系统 SHALL 将云端模型调用结果区分为成功、永久拒绝、认证或余额错误、限流、瞬时网络故障、供应商故障和无效结构响应，并在任务及异常记录中保留不含秘密的错误类别、模型、尝试次数和时间。

#### Scenario: 供应商返回 HTTP 403
- **WHEN** 模型路由返回 HTTP 403 或明确的供应商政策拒绝
- **THEN** 系统记录永久拒绝，不把它显示为超时
- **AND** 记录中不得包含 API Key 或其他凭据

#### Scenario: 连接被意外中断
- **WHEN** 请求出现连接超时、读取超时或 SSL EOF
- **THEN** 系统记录瞬时网络故障，并与 HTTP 403 分开统计

### Requirement: 重试必须按故障类型有界执行
系统 MUST 只对瞬时网络故障、HTTP 429 和可恢复的 5xx 执行有界退避重试；对相同请求的 400、401、402、403、413 和参数兼容错误不得原样重试。

#### Scenario: 瞬时故障后恢复
- **WHEN** 首次请求出现允许重试的瞬时故障
- **THEN** 系统在带抖动的递增等待后重试
- **AND** 总尝试次数不得超过配置上限

#### Scenario: 永久拒绝
- **WHEN** 请求返回不可重试的永久错误
- **THEN** 系统立即返回结构化失败，不执行同模型同载荷的网络重试

### Requirement: 重复永久错误必须触发熔断
同一任务中相同模型路由连续出现达到阈值的永久错误时，系统 MUST 打开模型通道熔断并停止继续发送同类请求；熔断事件 SHALL 可在任务详情和异常监控中观察。

#### Scenario: 连续三次相同 403
- **WHEN** 同一设备任务对同一模型路由连续三次获得相同 403 指纹
- **THEN** 系统打开本任务模型通道熔断
- **AND** 后续视频不得继续发送相同模型请求

#### Scenario: 新任务探测模型通道
- **WHEN** 前一任务因熔断结束且新的明确验证轮次开始
- **THEN** 新任务可以执行一次受控通道探测
- **AND** 探测失败时再次快速收口，不恢复无上限请求

### Requirement: 模型请求必须按能力适配
系统 SHALL 根据候选模型实际支持的图片输入、流式输出、JSON Object 和 JSON Schema 能力构造请求；模型切换不得仅替换模型名称而继续发送不兼容参数。

#### Scenario: 模型不支持严格 JSON Schema
- **WHEN** 候选模型支持 JSON Object 但不保证严格 JSON Schema
- **THEN** 系统使用兼容请求格式并在本地执行完整字段、枚举和类型校验
- **AND** 无效输出按结构响应失败处理，不进入设备动作

### Requirement: 模型切换必须先完成只读回放
候选视觉模型在成为正式主模型前 MUST 使用已保存截图执行有样本上限的只读回放，并比较请求成功率、有效结构响应率、主题一致性、延迟和费用；回放不得连接或操作设备。

#### Scenario: GLM 候选模型评测
- **WHEN** 系统评测新的 GLM 多模态候选模型
- **THEN** 评测使用版本化提示词和同一批本地截图
- **AND** 报告分别列出模型错误、结构错误、主题结果、延迟和估算费用

### Requirement: 二十视频循环必须使用完整成功口径
每轮验证 SHALL 处理 20 个视频并保存轮次结果；只有所需模型判断、页面流程和任务收口均满足规格时才计为完整成功，模型失败后安全跳过不得计为完整成功。

#### Scenario: 达到阶段目标
- **WHEN** 连续执行 10 个二十视频轮次
- **THEN** 至少 9 个轮次必须完整成功
- **AND** 所有进入主题模型的画面中至少 95% 返回有效结构化判断
- **AND** 不得发生结果不明动作的自动重放

#### Scenario: 未达到阶段目标
- **WHEN** 十轮窗口内完整成功少于 9 轮或模型有效响应率低于 95%
- **THEN** 系统保留本轮证据并将目标标记为未达成
- **AND** 下一轮修改必须基于错误类别和截图证据，不得通过隐藏失败或扩大跳过来提高数字
