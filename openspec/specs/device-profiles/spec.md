# device-profiles Specification

## Purpose
让同一套固定执行器在不同 Android 真机上依据稳定设备身份读取可验证的能力与界面兜底参数，并优先通过语义节点恢复页面，避免按分辨率复制多套易漂移程序。

## Requirements

### Requirement: 持久化设备能力档案
系统 SHALL 按稳定设备 ID 保存友好名称、型号、画面尺寸、密度、系统导航信息、控制能力和最后验证时间，并允许未知或变化后的设备重新探查而不复用不匹配的兜底参数。

#### Scenario: 已知设备重新接入
- **WHEN** 已建档设备以相同稳定设备 ID 接入且关键显示特征一致
- **THEN** 系统显示友好名称并将对应能力档案提供给统一固定执行器

#### Scenario: 显示特征发生变化
- **WHEN** 已建档设备的画面尺寸、密度或系统导航信息与档案不一致
- **THEN** 系统标记档案需重新验证且不得静默使用旧的绝对坐标

### Requirement: 语义优先恢复主信息流
固定执行器 SHALL 在恢复主信息流时优先查找可见、可点击的“首页”语义节点，并只在节点不可用时使用设备档案中的归一化兜底位置；每个动作后 MUST 验证已回到主信息流。

#### Scenario: 停留在我的页面
- **WHEN** 抖音前台处于带底部导航的“我”页面且存在可点击“首页”节点
- **THEN** 系统点击该节点并在验证主信息流后继续，而不是只返回或重启应用

#### Scenario: 语义节点缺失
- **WHEN** UI 树无法提供可点击“首页”节点但设备档案含已验证兜底位置
- **THEN** 系统使用归一化兜底位置执行一次点击并验证结果，失败则安全留证停止

### Requirement: 新设备验证前不复用坐标兜底
系统 SHALL 为新发现的稳定设备 ID 保存只读探查事实，并在 Mobile Harness 与 uiautomator2 截图/UI 树前检通过前保持 `verified=false` 和空坐标兜底。

#### Scenario: 新华为首次接入
- **WHEN** `8KE5T19514001258` 以 `device` 状态接入且尚无档案
- **THEN** 系统保存实际型号、显示特征和控制模式，但不得复制其他华为机型的 `home_fallback`

#### Scenario: 只读前检全部通过
- **WHEN** Mobile Harness 和 uiautomator2 都能读取该设备截图与 UI 树，且显示签名与档案一致
- **THEN** 系统可以标记档案已验证，同时继续保持未单独校准的坐标兜底为空

### Requirement: 分离设备能力与平台控制档案
系统 SHALL 分别保存稳定设备能力档案和按设备、平台包名、App 版本、显示签名与 Adapter 版本区分的平台控制档案。

#### Scenario: 同一设备初始化抖音
- **WHEN** 设备控制能力和抖音校准通过
- **THEN** 系统保存共享设备能力以及独立抖音平台档案，不复制完整任务脚本

### Requirement: 控件档案必须可验证
平台控件档案 SHALL 保存语义定位依据、归一化区域、来源、置信度、验证证据和验证时间；未经固定程序复验的 AI 候选 MUST NOT 标记为可执行。

#### Scenario: 视觉候选通过页面转移验证
- **WHEN** 固定程序确认候选控件属于目标前台包且动作后进入预期页面
- **THEN** 系统可将该候选保存为已验证的平台控件

### Requirement: 旧档案兼容与局部失效
缺少初始化元数据的现有档案 SHALL 继续支持既有语义流程并显示为旧档案；显示或 App 签名变化时系统 SHALL 禁用过期坐标并标记平台档案 `stale`，不得删除历史数据。

#### Scenario: App版本发生变化
- **WHEN** 当前抖音版本与平台档案记录不同
- **THEN** 语义识别仍可使用，旧坐标兜底被禁用且设备提示快速复验

### Requirement: 互动巡检校准必须绑定设备和版本
系统 SHALL 按稳定设备 ID 保存互动巡检 v2 校准档案，包括应用版本、显示签名、三遍校准结论、页面语义、分区能力和已验证的归一化坐标后备。任务提交时 MUST 冻结档案快照，且不得把一台设备的坐标后备复制给另一台设备。

#### Scenario: 稳定档案提交 v2 任务
- **WHEN** 同一设备后两遍校准的页面语义与返回路径一致，且当前应用版本和显示签名匹配档案
- **THEN** 系统冻结该设备的 v2 档案快照并允许提交互动巡检任务

#### Scenario: 版本或显示签名漂移
- **WHEN** 当前应用版本或显示签名与任务冻结快照不一致
- **THEN** 固定执行器失败关闭并提示重新校准，不尝试其他设备的坐标
