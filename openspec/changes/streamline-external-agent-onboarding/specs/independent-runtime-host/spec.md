## ADDED Requirements

### Requirement: Windows共享读句柄下的有界原子心跳
后台 SHALL 使用自身唯一临时文件发布完整心跳，Windows短暂共享拒绝时允许至多400ms有界替换重试。持续拒绝和其他文件错误 MUST 保留失败，不扩大既有停机总截止或降低实际进程退出与最终心跳核验要求，不因单次写失败继续覆盖程序。

#### Scenario: 停止期间短暂读取最终心跳
- **WHEN** 最终心跳替换被短暂读取句柄阻止且句柄在400ms内释放
- **THEN** 原子发布完整停止回执，仅在实际进程和心跳核验通过后报告停止

#### Scenario: 持续拒绝替换
- **WHEN** 文件持续占用或权限错误未恢复
- **THEN** 有界失败、原文件保持完整，仅清理本次临时文件，保留诊断并阻止安装
