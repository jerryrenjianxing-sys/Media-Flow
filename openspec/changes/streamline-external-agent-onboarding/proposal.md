# dev.51：项目规范与外部 Agent 接入

## Why
真实 Trae 首次接入耗时12分57秒：默认复制的约91KiB材料要求重建17个文件，发生分页阅读和上下文交接；最终只读检查本身成功。能力介绍混淆登记、就绪、执行与评论预览。

## What Changes
- 保留现有首页设计，复制改为不超过4KiB的本机连接说明；ZIP及完整Markdown参考导出兼容。
- 用一个连接模块生成本机资料、连接卡和HTTP身份；客户端每次重读显式连接文件，首次检查一次GET共享5秒截止。
- 简短Skill按目标引导，规范术语、模块地图和阅读入口；先失败回归，再实现，独立规范/需求评审。
- dev.51隔离安装及本机接管，GitHub草稿在真实Trae验收通过后才公开。

## Non-goals / Safety
不重做Electron、队列或固定执行器；不操作设备、不调用业务模型、不移动数据、不恢复任务。无自动启动服务、聊天授权账本或全盘发现。旧失败与未验收记录保持。

## Impact / Rollback
影响execution-architecture、project-governance、首页、连接客户端与发行说明。连接文件不含凭据，位于既有外部数据根，禁止进入发行资产。失败回退程序/后台登记，不覆盖数据库。真实Trae记录缺失时保持草稿，不能用接口速度代替体验。
