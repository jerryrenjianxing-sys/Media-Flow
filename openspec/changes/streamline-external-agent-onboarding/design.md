## Interface
连接模块提供运行描述、原子发布和连接说明三个操作，隐藏地址、运行模式、运行时及身份组装；只读HTTP不产生文件。启动时发布既有数据根中的agent-connection.json；文件和HTTP来自同一描述。描述绑定产品、实例、数据根及当前程序，升级保留资料文件位置。

客户端显式--connection-file优先，逐次读取地址及包内运行时，并在同一次GET核对身份；缺失/损坏/错误实例分别返回确定原因。无此参数的旧配置与请求回执语义不变。连接成功只证明平台身份可达，运行时缺失单列，登记快照不证明设备在线。

复制卡只指向已存在Skill及PowerShell，不要求文件重建。可移植ZIP不携带本机路径；完整Markdown只作参考。主Skill不超过8KiB，技术规则放到目标分支参考。preview_only只控制评论发送，不是任务执行开关。
