## Context

按用户批准的docs/dev39-plan.md分层修复。现有固定执行器为唯一设备通道，终态不可逆。

## Goals / Non-Goals

目标是容忍零散错误而不伪造成功；等待可观察并可停止。非目标见proposal。

## Decisions

模型逻辑请求统一截止和尝试预算，临时异常不算永久错误。检查点使用同一SQLite事务；每个动作前写pending标记，确认后写结果。等待状态与占用锁分离但保留同设备顺序。跨进程探针租约保存在同一任务库，过期租约可接手。旧无检查点运行崩溃仍按旧规则失败，不能猜测续跑位置。

## Risks / Trade-offs

无截止批次可长时间等待但必须有next_check和停止入口。恢复重新验证身份/目标流，不重放已消费视频。单台暂停不得扩散，凭证硬错误等待人工不反复请求。窗口重启后未知写入停相应能力且不能算成功。

## Migration Plan

增量表和字段，不改历史终态。全部离线与真实模型验证通过才本机部署；失败回退程序而不覆盖数据库。正式任务新建而不恢复失败批次。
