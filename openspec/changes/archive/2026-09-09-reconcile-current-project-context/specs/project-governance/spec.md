## ADDED Requirements

### Requirement: 现行上下文与历史隔离
项目 SHALL 登记当前操作文档、历史材料及待验证差距；当前入口不得同时指导已退役的启动链或已替代的用户门槛。历史验收事实 MUST 保留，不能通过文字更新伪造实现完成。

#### Scenario: 从新上下文读取项目
- **WHEN** Agent 不携带历史聊天而读取项目入口
- **THEN** 能找到当前入口、Skill、MBH 开发带测方法和未完成事项，不需要恢复内置聊天或旧巡检

#### Scenario: 清理旧指引
- **WHEN** 文档或本机项目相关记忆中的流程已被替代
- **THEN** 现行指引更新，旧事实进入历史引用；删除重复内容有精确清单，运行数据和兼容代码不受影响

### Requirement: 文档交付一致性验证
项目 SHALL 校验现行文档的本地链接、废弃操作要求和完整 Skill 的复制下载一致性；检查范围及历史例外必须显式登记。

#### Scenario: 引入过时操作
- **WHEN** 现行材料重新出现退役入口或失效本地链接
- **THEN** 离线检查失败并列明文件和原因，不通过连接设备验证文档

#### Scenario: Skill 内容更新
- **WHEN** 平台 Skill 的说明或参考更新
- **THEN** Markdown 与 ZIP 从同一来源生成，并能重建相同客户端和参考文件
