## Context

用户已经批准清理计划。现行说明累积多代内容，本机 MBH 使用独立技能快照，不能仅检查仓库。业务行为本轮保持不变。

## Goals / Non-Goals

目标是可独立读取的现行索引、完整处置登记及防回归检查。非目标是修复设备动作、部署新服务、清理用户数据或复跑五机。

## Decisions

- 使用原有 PROJECT / STATUS / RUNBOOK 分工，STATUS 只留当前事实，原版本流水保留到历史记录。相比继续在顶部追加告示，移出旧指令能减少误读。
- 逐文件登记维护资料；主规格和活动变更保留路径，按能力适用范围标注旧兼容行为，不删除旧场景或勾选未验收任务。
- 机器可读登记驱动现行链接与过时要求检查，同时生成清理清单。历史验收不纳入现行禁词规则。
- MBH 仅更新本项目抖音卡片和已读的相关记忆；先保留原文备份，不升级运行依赖，不把本机绝对路径写入通用 Skill。

## Risks / Trade-offs

- 自动检查不等于理解全部业务 → 保留人工阅读验收与代码差距清单。
- 移动资料造成链接断裂 → 保留兼容索引并检查相对链接。
- 本机技能位于仓库外 → 精确记录修改目标、备份及可读验证；权限拒绝时如实报告，不假称同步完成。

## Migration Plan

先保存历史原文，更新现行入口、相关规格注记与 Skill；执行离线校验，不切换服务。回退仅恢复本轮文档与本机卡片备份，不覆盖数据库、任务或设备状态。
