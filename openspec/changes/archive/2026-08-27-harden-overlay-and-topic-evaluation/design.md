## Context

固定执行器已经使用语义 UI 树和截图做动作前检查，MBH 仅用于开发期未知页面恢复。当前主题模型采用 `exact / adjacent / unrelated / uncertain` 协议，但提示词内联在请求函数中，且模型输出没有与人工确认标签形成可重复的差异报告。

## Goals / Non-Goals

**Goals:**

- 把一次成功的弹窗恢复沉淀为秒级回归测试和固定程序规则。
- 用同一截图建立“参考标签—RiskFlow 判断—差异报告”的离线闭环。
- 让主题提示词有稳定版本标识，便于比较修改前后结果。

**Non-Goals:**

- 不让 Codex、MBH 或云模型直接点击生产设备。
- 不把另一个模型的输出未经人工确认就当成训练真值。
- 不在本变更中微调模型权重、自动切换生产模型或执行真实互动。
- 不提交包含用户隐私的运行截图；评测清单只引用本地证据路径。

## Decisions

### 已知弹窗使用白名单恢复器

启动恢复只匹配“未成年人模式”或“青少年模式”等明确文案。匹配后优先点击可见语义“关闭”控件，每次只做一个动作并重新观察；弹窗消失但评论面板仍在时交回既有主信息流恢复。相比统一点击右上角坐标，这能跨分辨率复用并避免在未知页面误点。

### 参考模型只提出候选标签，人工确认后进入金标准

Codex/MBH 视觉判断或第二云模型可以生成 `reference_relevance`、证据和备注，但样本必须带 `confirmed=true` 才参与准确率统计。未确认样本只进入待复核列表。相比“模型教模型”，这能防止同源偏差和错误自强化。

### 评测只比较可观察输出

评测器读取 JSONL 清单和 RiskFlow 决策 JSON，计算已确认样本的一致率、类别混淆和逐样本差异，不访问设备、不发送互动。图片保留在 `runtime/`，清单使用相对或绝对本地路径，不复制图片进源码目录。

### 提示词采用固定版本常量

主题系统协议和用户任务模板从请求函数中提取为独立常量/构造函数，评测结果记录提示词版本。只有新提示词在金标准集上没有已知回归，才由人工决定是否进入运行配置；程序不自动覆盖生产提示词。

## Risks / Trade-offs

- [UI 树仍可能无法暴露弹窗关闭按钮] → 只记录恢复失败并交由既有有界返回/重启流程，不使用跨设备盲点坐标。
- [参考标签可能带有 Codex 或人工偏差] → 强制保存证据、边界备注和确认状态；扩大样本前不宣称长期准确率。
- [单帧无法代表整段视频] → 允许 `uncertain`，并在评测报告中单列，不强行二元化。
- [云模型评测产生费用] → 默认离线比较已有结果；显式调用模型前展示样本数和模型配置。

## Migration Plan

1. 先补弹窗恢复和评测器红灯测试，不接触运行数据库。
2. 实施白名单恢复、固定提示词版本和离线比较器，运行全部离线测试。
3. 在任务池暂停、互动概率为零时做单设备最小启动验证；没有弹窗时只验证规则不误触。
4. 回退时恢复执行器和提示词构造；评测 JSONL 与报告为只读证据，可直接保留，不影响历史任务和设备状态。
