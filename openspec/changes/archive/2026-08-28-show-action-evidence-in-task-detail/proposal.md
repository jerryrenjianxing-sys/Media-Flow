# Change: 在任务详情按动作查看既有截图

## Why

任务详情已经展示每轮视频、点赞、收藏、评论和纠错数量，但现有截图集中在通用运行截图区域，使用者无法从某个结果数字直接核对对应证据。执行器本身已经保存多类截图，本变更只整理并展示已有证据，不新增设备动作或截图时机。

## What Changes

- 详情接口按视频、点赞、收藏、评论和纠错返回已有截图索引。
- 点赞和收藏只展示日志已确认动作生效的发送后截图。
- 评论只展示任务结果中已登记的发送成功截图，纠错只展示已登记异常截图。
- 任务详情中有截图的统计块可点击展开对应图库；没有截图的统计块保持普通显示。

## Impact

- Affected spec: `records-browser`
- Affected code: `fixed_runner/control_api.py`、`control_console/app/components/task-groups.tsx`、样式与测试
- 不改变固定执行器、任务队列、截图时机、设备控制或历史文件。
