## Context

当前完整方案保存在 `automation_profiles` 的 `default` 项中，控制台直接编辑整份配置。预设需要复用这套存储，但必须与正式方案隔离，并限制可覆盖字段。

## Goals / Non-Goals

**Goals:**

- 非技术用户可以一键套用常用参数组合。
- 可以命名保存当前策略并在以后复用。
- 预设不会改变设备池、密钥、随机种子和发送安全状态。

**Non-Goals:**

- 不自动提交任务，不自动保存为正式方案。
- 不允许删除内置预设，不同步到云端，不跨电脑共享。
- 不把设备编号、API Key 或 `preview_only` 写入预设。

## Decisions

- 复用 `automation_profiles`，自定义预设使用 `preset:` 前缀；不新增表。
- 后端维护策略字段白名单，对传入完整配置先执行现有校验，再只保存允许字段。
- 内置预设由代码返回并标记只读；自定义名称去除首尾空格，限制 1 到 40 个字符，不能覆盖内置名称。
- 应用只修改浏览器表单；用户仍需点击“保存方案”或“提交任务”才产生后续行为。
- 删除自定义预设通过明确按钮触发，接口拒绝删除内置项。

## Risks / Trade-offs

- [预设覆盖安全开关] → `preview_only` 不在白名单中，应用时保留当前值。
- [预设覆盖设备池] → `device_id` 和 `device_ids` 不在白名单中。
- [名称冲突] → 自定义同名保存视为更新；内置名称禁止覆盖。
- [旧记录污染列表] → 只枚举 `preset:` 前缀，正式 `default` profile 不展示。

## Migration Plan

无需数据库迁移。回退时移除接口和界面，自定义 `preset:` profile 可安全保留或以后经用户确认删除。
