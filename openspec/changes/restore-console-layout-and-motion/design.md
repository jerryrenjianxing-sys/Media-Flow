## Context

当前七页已经共享固定桌面侧栏，但侧栏同时承担导航、在线状态、队列状态和主题切换，主内容缺少稳定的页面级顶部锚点。内容资产页继续沿用普通双栏表单：左侧列表高度很短，右侧主题字段完整展开，导致大屏首屏比例失衡。状态接口当前验证为五台设备在线、正式队列为空，因此截图中的“0 台设备在线”属于前端加载/错误语义缺陷，不是设备事实。

## Goals / Non-Goals

**Goals:**

- 恢复会议演示所需的正式产品层级，让页面名称、状态和高频全局操作首屏可见。
- 让内容计划的浏览、编辑和主题轮换顺序在一个桌面视口内可理解。
- 恢复有节制、可关闭、不会妨碍操作的 GSAP 动效。

**Non-Goals:**

- 不重写内容计划业务逻辑，不改变保存、归档和版本冻结语义。
- 不改变设备发现、任务状态或后台进程，不用界面改动掩盖真实 API 故障。
- 不增加移动端产品布局，不操作真机或模拟器。

## Decisions

### 1. 侧栏负责导航，顶部工作区负责当前上下文

侧栏保留分组导航和低频环境摘要；主内容增加 56px 粘性顶部工作区，显示当前页面名称、简短说明、在线设备和队列摘要，主题切换固定在右上角。这样高频信息不会被挤到侧栏底部，也不会因页面内容滚动而消失。

### 2. 未知状态不得显示为零

状态首次读取前显示“正在读取设备”，请求失败显示“本机服务未连接”，只有接口成功返回后才显示实际数量。顶部和侧栏消费同一状态快照，避免两套文案漂移。

### 3. 内容资产使用分区编辑和单主题展开

计划列表保持固定窄栏；编辑区按“计划设置、主题队列、保存版本”分区。主题卡默认只展开当前编辑项，其余显示名称、搜索词和启用状态摘要；切换展开只影响表现，不改写草稿。相比把全部主题字段永久平铺，这能显著缩短页面并保留全部能力。

### 4. GSAP 只用于上下文转换

GSAP 负责路由页面的短距离进入、标记分区的轻微错峰渐入以及以主题按钮为圆心的明暗主题过渡。侧栏不再使用 Flip 移动主工作区：外壳始终只预留 72px 图标轨道，展开层覆盖主工作区；GSAP 仅补间侧栏宽度和文字透明度。动画不绑定状态轮询，不循环播放；系统开启 `prefers-reduced-motion` 时直接完成状态切换。

侧栏交互参考 Gemini 的稳定导航轨道：菜单按钮和图标在展开前后保持位置，抽屉只改变容器几何，文字随后短距离渐显。RiskFlow 保留自己的色彩、状态语义和五工作区结构，不复制 Gemini 品牌或聊天信息架构。

侧栏实现集中到一个共享模块，完整负责品牌、分组导航、自有线性图标、折叠提示和底部运行状态。页面壳只消费该模块的收起状态与路由接口，避免每个页面拼装自己的侧栏变体。

任务台以自身容器宽度而不是浏览器视口决定排版：不足 1100px 时摘要落到表单下方，不足 720px 时搜索段和主页段纵向排列。阶段名称和数字标签统一禁止逐字换行。

### 5. 设计来源必须落到可执行令牌

根目录 `DESIGN.md` 只保留原始 Linear 风格研究，不假装被运行时读取。控制台通过 `control_console/DESIGN.md` 记录产品适配，通过 `app/design-tokens.css` 实际提供明暗主题令牌；页面样式消费令牌而不是复制来源文档中的色值。

## Risks / Trade-offs

- [主题切换遮罩可能短暂覆盖操作] → 动画总时长控制在 700ms 内且遮罩不接收指针事件。
- [折叠主题卡让字段暂时不可见] → 卡头持续展示主题名称、搜索词、启用状态和明确的“展开编辑”入口。
- [脏工作区包含大量既有改动] → 只编辑共享外壳、内容资产页、全局样式、对应测试和本 change，不格式化或回退其他文件。
- [开发热更新可能再次出现 Vite 错误遮罩] → 最终使用生产构建和独立浏览器页面验收，不把开发模式错误遮罩当作正式页面。

## Migration Plan

1. 先增加规格和渲染测试断言。
2. 更新共享外壳和内容资产页，不触碰 API 与运行数据。
3. 严格校验规格，运行控制台测试、lint 和生产构建。
4. 在深浅主题与多个桌面尺寸做真实页面截图验收。
5. 若回滚，只恢复本次四个前端文件和测试；数据库、任务、设备及证据不受影响。
