## ADDED Requirements

### Requirement: 更新发现只依赖已公开发行
桌面 SHALL 从GitHub Release列表发现最高已公开dev发行，排除草稿、未发布时间和非dev版本；仅有标签不得视为发行。查询最多3页每页100条且共享10秒截止。MUST 保留原下载、SHA512和安装链，不引入客户端发布凭据或降级。

#### Scenario: 候选标签已公开但资产仍为草稿
- **WHEN** dev.53标签存在但对应Release仍为草稿，最高公开版为dev.50
- **THEN** 忽略草稿，分别展示本机与公开版本，不请求草稿资产或降级

#### Scenario: 在线检查失败
- **WHEN** 网络失败、请求截止或公开发行资料不完整
- **THEN** 显示检查不可用而非安装失败；自动检查不占首页错误横幅，手动检查可重试和查看日志，不将其解释为后台故障
