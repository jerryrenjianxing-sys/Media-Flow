## ADDED Requirements

### Requirement: 内嵌Agent独立运行及依赖固定
Windows 安装包 SHALL 携带已校验的原生 Agent 运行时、所需依赖、流程指南及许可证说明；首次启动和日常运行 MUST 不依赖 Codex、WSL、系统 PATH 中开发工具或源码目录，也不得静默下载并运行未锁定版本的组件。

#### Scenario: 全新Windows用户安装
- **WHEN** 在没有 Codex、WSL 和开发环境的 Windows 用户下安装并提供自己的模型凭证
- **THEN** 能从首页建立会话、调用平台工具和恢复会话，网络不可用时本地启动仍正常且模型调用明确失败

#### Scenario: 升级后恢复
- **WHEN** 同一用户升级软件
- **THEN** 会话、记忆、原生 Agent 认证数据、既有 MediaFlow 凭证和修复候选保留在用户数据目录，既有设备与任务数据不被覆盖，不自动重放旧工具操作

### Requirement: 安装版具备真实修复工作区
发布包 SHALL 包含与发布提交匹配的可审计修复源材料和锁定的本地测试资源，使 Agent 可在无外部源码目录时编辑和验证候选。实际程序部署 MUST 仍经过统一版本发布，候选工作区不作为第二份自动运行服务。

#### Scenario: 安装版修复验收
- **WHEN** 已安装软件在隔离工作区修改一个测试样例并运行回归
- **THEN** 展示真实差异和测试回执，不依赖开发机路径，活动 API 仍报告原发布身份

#### Scenario: 发行内容扫描
- **WHEN** 构建含 Agent 的安装包
- **THEN** 扫描确认包含依赖版本和许可证且无个人 API Key、原生 auth.json、OpenCode 个人配置或历史、运行库、截图、设备身份与私人模板；同号不同提交继续被拒绝
