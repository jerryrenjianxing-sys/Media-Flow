## ADDED Requirements

### Requirement: 内嵌Agent通过工具编排而非直接动作
内嵌 Agent 的模型 SHALL 只产生计划、工具意图和修复候选；本地工具服务 MUST 验证会话、参数、确认和幂等身份后调用既有规划、队列与维护操作。设备点击、输入、页面恢复及验证继续由持有同一设备独占锁的固定执行程序完成。

#### Scenario: Agent 提交视频任务
- **WHEN** Agent 为用户确认后的计划调用执行工具
- **THEN** 工具服务生成冻结任务并交给现有 Worker，不开启 Agent 自己的 ADB 点击循环

#### Scenario: Agent 请求删除实例
- **WHEN** Agent 提议删除或重建虚拟机
- **THEN** 使用既有准确清单、占用阻断及用户确认，聊天中的模型声明不能伪造确认

### Requirement: 专业修复工具与活动运行隔离
系统 SHALL 允许内嵌 Agent 在修复工作区编辑和测试程序，同时 MUST 区分项目授权与操作系统权限。工具权限不得被描述为操作系统沙箱；程序级保护必须由实际执行服务检查，外部命令不能绕开设备锁、确认或覆盖当前安装目录。

#### Scenario: 测试夹具试图使用生产数据
- **WHEN** 修复测试配置指向实际任务库、密钥目录或在线设备
- **THEN** 测试入口拒绝并提示使用隔离资源或发起单独的设备验证计划

#### Scenario: 统一发布修复
- **WHEN** 修复经验证进入正式发布提交
- **THEN** 新版本记录唯一提交和资产哈希，客户端使用统一更新流程；工作区修改本身不会改变活动程序
