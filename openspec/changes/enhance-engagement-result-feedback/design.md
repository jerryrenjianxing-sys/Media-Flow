## Decisions

### 独立回执作为长期事实

每次 v2 以独立 `interaction_inspections` 记录结束状态、结果类型、可读分区摘要和证据清单。提醒只负责未查看状态并引用回执；清空普通任务记录不删除回执。

### 只去除无意义数据

每个页面入口证据保留；滑动后画面内容哈希相同时删除重复文件。可见昵称、摘要、时间和数量按实际存在写入，缺失字段不写入 JSON。截图保留 PNG，UI 树使用 gzip，均永久保留且纳入现有证据库存。

### 确认后仍能看到刚才结果

确认接口返回实际确认 ID。横幅跳转 `/interactions?view=all&focus=...`，页面在全部历史中高亮对应回执。旧提醒没有回执时单独标记为旧版摘要。

### 动作边界不变

可读内容仅从列表级 UI 树提取。固定程序仍禁止打开会话、回复、回赞、关注、他人主页和设置控件。
