## MODIFIED Requirements

### Requirement: v2 证据长期保留且按内容去重
系统 SHALL 长期保存页面入口截图、有效滑动截图及对应压缩 UI 树。相同画面 MUST 在同一次巡检中去重，失败巡检 MUST 保留停止前已经采集的有效证据。

#### Scenario: 成功巡检
- **WHEN** v2 完整结束
- **THEN** 证据继续存在并可通过回执证据 ID 在本机读取

#### Scenario: 滑动后画面未变化
- **WHEN** 新画面与本次已保存画面的内容哈希相同
- **THEN** 系统删除重复文件且不新增证据项

### Requirement: 列表级可读内容进入本地回执
系统 SHALL 保存消息列表、点赞、评论、弹幕和访客页中实际可见的昵称、摘要、时间与数量。不存在的字段 MUST 被省略，采集过程 MUST NOT 打开会话或执行对外互动。

#### Scenario: 可见行只有昵称和摘要
- **WHEN** UI 树没有可靠时间或角标数量
- **THEN** 回执只保存昵称与摘要，不写入空时间或虚假数量
