## Context

现有首页是单页 React 工作台，配置状态集中在 `page.tsx`，样式由 `globals.css` 提供；本次不改变后端接口或数据模型。

## Goals / Non-Goals

**Goals:** 让常用任务在首屏内完成，减少术语和同时可见字段，并保留精确控制。

**Non-Goals:** 不重写框架、不新增依赖、不拆分 API、不改运行和设备安全行为。

## Decisions

- 使用“快速配置 + 高级设置”双层结构，所有控件绑定同一 `Config`，避免重复状态和同步错误。
- 快速互动强度只提供语义化快捷按钮，点击时写入既有概率字段；高级滑杆仍是最终精确值。
- 页面顶部用四个锚点步骤呈现当前完成状态，右侧提交卡持续显示任务摘要和阻塞原因。
- 保留现有视觉语言，增强字号、留白、选中态和说明层级，不引入新组件库。

## Risks / Trade-offs

- [快捷强度可能覆盖用户精确值] → 仅在用户主动点击强度按钮时写入，默认只显示根据当前概率推导的状态。
- [高级设置折叠后能力不易发现] → 显示包含内容和已修改状态，且从快速区提供明显入口。
- [页面重排影响旧测试] → 保留关键文案与可访问标签，并新增快速配置与摘要断言。

## Migration Plan

只更新控制台静态资源。构建通过后重载页面；回滚只需恢复页面与样式文件，不触碰数据库、队列、截图或设备状态。
