## ADDED Requirements

### Requirement: 传输阶段诊断完整脱敏
模型诊断 SHALL 区分连接、上传、读取、解析及HTTP响应错误，保留实际尝试次数和耗时；已有结构化传输失败不得重新解释为格式或Key错误。展示 MUST NOT 暴露凭据或完整上游正文，不改变既有请求截止或重试次数。

#### Scenario: 慢速上传或读取失败
- **WHEN** 隔离请求在上传或读取阶段超时
- **THEN** 回执保留对应传输阶段与临时失败分类，页面提供相符中文说明

#### Scenario: 上游错误包含秘密
- **WHEN** 错误正文包含凭据或原始请求材料
- **THEN** 仅公开白名单诊断字段和脱敏原因
