## MODIFIED Requirements

### Requirement: 运行监控与任务结果职责分离
控制台 SHALL 在任务台完成任务提交；运行页 SHALL 只显示队列状态、设备进度、最近恢复动作、人工阻断以及暂停、安全停止和取消等待任务等运行控制，不得编辑或提交任务参数。设备进度 SHALL 每台活动设备最多展示一张卡，并优先展示该设备当前执行中的任务；仅当该设备没有执行中任务时，才展示下一条等待任务。

#### Scenario: 多设备预先创建多轮任务
- **WHEN** 多台设备各有一个执行中任务和多个后续等待任务
- **THEN** 顶部执行中数量与设备进度卡片的执行中状态一致
- **AND** 每台设备只展示当前执行中的一轮，不得被较晚创建的等待轮次覆盖

#### Scenario: 设备只有等待任务
- **WHEN** 某台设备没有执行中任务但存在等待任务
- **THEN** 设备进度展示该设备下一条将执行的任务并明确标记为等待中
