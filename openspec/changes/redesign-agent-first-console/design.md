## Context
当前dev.22，固定执行器和接口保持。界面同时存在旧轨道导航和Agent侧栏；广泛样式与双滚动导致可读性问题。
## Goals / Non-Goals
目标是统一全站可操作界面、明确对话阶段及手机/桌面适配。非目标是改变设备、模型配置或发布安装包；Skill与默认工具可用性在现有OpenCode变更中同步。
## Decisions
保留React/Vinext与组件，采用统一token、应用头部和管理导航；Agent首页240px会话栏、860px阅读区、按需详情抽屉。公共控件使用专属类，移除全局通配字号和图标污染，不更换框架。设置入口复用Agent设置并按模型、操作指南、偏好、数据、关于分组；按用户最新要求取消会话等级控件，许可默认折叠。Enter走同一幂等发送入口，IME组合键例外。任务/设备停止与停止回答明确分离。
## Risks / Trade-offs
广泛CSS影响旧页 → 全路由明暗及缩放截图验收；类型修复不得使用全局any跳过。对话恢复风险在现有Agent变更中单独规定。
治理页评测与证据库存独立加载，部分失败保留已取得的数据并提供重试，未知数量不显示为零。库存读取沿用原白名单和统计口径，流式汇总文件元数据、在进入目录前排除原本不计入的备份目录，避免重复逐文件查询及保留全量路径。此优化不改变证据、备份、保留政策或图片访问许可。
## Migration Plan
dev.23离线验证后干净提交，空闲安全切换本机。保留旧dist和提交回退路径，不删数据库或重启MuMu；不打包、不推送。验收未通过不归档。
