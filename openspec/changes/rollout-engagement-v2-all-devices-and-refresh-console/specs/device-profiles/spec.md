## ADDED Requirements

### Requirement: 互动巡检校准必须按设备和运行签名隔离
系统 SHALL 按稳定设备 ID、抖音 App 版本、显示签名和校准档案版本保存互动巡检 v2 控件与页面语义。任务提交时 MUST 冻结匹配档案；运行签名不匹配时不得复用其他设备或版本的坐标后备。

#### Scenario: 同分辨率但 App 版本不同
- **WHEN** 两台设备显示尺寸相同但抖音 App 版本不同
- **THEN** 系统分别读取各自验证过的互动巡检档案
- **AND** 不因尺寸相同而共享未验证的资源标识或坐标

#### Scenario: 任务开始前签名漂移
- **WHEN** 当前 App 版本或显示签名与任务冻结档案不同
- **THEN** 互动巡检以校准失效原因失败关闭
- **AND** 不执行任何坐标后备点击

### Requirement: 校准通过需要连续稳定语义
设备互动巡检档案 MUST 只在三遍 MBH 白名单流程中后两遍页面语义、动作顺序和恢复结果一致时标记为 v2 可执行。缺失入口或页面歧义 MUST 保留为设备级能力事实，不得推广成通用控件。

#### Scenario: 后两遍一致
- **WHEN** 同一设备后两遍校准均通过相同语义入口并返回首页
- **THEN** 系统可保存版本化 v2 档案及已验证的归一化坐标后备

#### Scenario: 后两遍出现差异
- **WHEN** 同一目标在后两遍出现不同页面、资源标识或歧义控件
- **THEN** 系统保持该设备未校准状态并记录失败原因
- **AND** 不向该设备提交固定 v2 巡检
