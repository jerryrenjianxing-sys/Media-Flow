## Why

当前互动巡检 v2 只对抖音5号的 33.0.0 页面和显示签名完成校准，其余四台真机运行 37.5.0、40.1.0 或 40.2.0，直接复用单设备规则会把版本差异误当成可执行控件。与此同时，控制台七个页面重复实现顶部导航，桌面信息层级、字号和互动巡检反馈不一致，需要在五设备同口径回执基础上统一重排。

## What Changes

- 对抖音1～4号分别完成三遍 MBH 安全校准，并复核抖音5号现有 v2 签名；只有后两遍语义一致的设备才能启用 v2。
- 将互动巡检校准规则改为设备、App 版本和显示签名共同限定的版本化档案，提交任务时冻结档案快照。
- 五台真机各执行一次独立 v2 巡检，不运行视频轮次；每台保留可读回执、有效截图和配对 UI 树。
- 将七个控制台页面统一为桌面侧栏工作台，统一品牌、导航、状态、主题、标题、卡片、表格、弹窗和证据画廊。
- 互动巡检页增加五台最近结果总览，明确区分有互动、无互动、未完成和校准异常。
- 非目标：不改变每5轮触发一次的正式节奏，不改变视频轮数、互动概率、评论策略，不适配手机端，不增加任何对外互动。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `engagement-inspection`: 增加多设备、跨 App 版本的 v2 校准档案冻结、五设备回执与未完成语义。
- `device-profiles`: 增加互动巡检专用的设备级版本化校准档案及签名失效规则。
- `console-page-workflow`: 将七个页面统一为桌面侧栏工作台，并增加五设备最近巡检总览。

## Impact

- 后端：设备档案、任务载荷、互动巡检固定规则、回执展示字段与相关测试。
- 控制台：共享工作台外壳、七页导航与布局、互动页总览、全局样式和渲染测试。
- 真机：五台已授权本地测试设备；列表访问可能清除未读角标，但点赞、收藏、评论、回复和关注保持为0。
- 依赖：不升级 Mobilerun、Portal、Python、Node 或前端依赖。
