## ADDED Requirements

### Requirement: 互动巡检保持列表级无外向动作
互动巡检 MUST 禁止打开具体私信会话、回复消息、发送表情、回赞、关注、戳一戳、访问对方主页或改变访客隐私设置。固定执行器只能点击已验证的消息、互动、访客、返回和首页语义控件；未知或歧义控件 MUST 失败关闭。

#### Scenario: 互动消息提供回赞按钮
- **WHEN** 收到的点赞列表同时显示用户信息和回赞、关注或私信快捷动作
- **THEN** 系统只读取当前列表信息并跳过所有快捷动作

#### Scenario: 私信卡片与系统卡片无法区分
- **WHEN** 当前消息页没有足够语义证明候选卡片是私信列表入口
- **THEN** 系统不得点击候选卡片并将该分区记录为失败

### Requirement: 未读状态副作用必须可见
系统 SHALL 在进入消息或访客页面前先记录可见未读角标，并在控制台明确说明打开列表可能清除平台未读角标或改变已查看状态；该副作用不得被描述为完全无状态读取。系统仍 MUST 禁止打开具体私信会话，以避免产生会话级已读行为。

#### Scenario: 消息入口存在未读角标
- **WHEN** 巡检开始时消息入口显示未读提示
- **THEN** 系统先记录该提示再进入消息列表
- **AND** 巡检详情标明列表访问可能已改变角标状态

### Requirement: 巡检敏感数据仅保存在本机
私信列表预览、互动用户和主页访客属于敏感本地运行数据，系统 MUST 只按有限条目保存到现有本机数据库或运行目录，不得发送至云模型、写入 Git、进入发布包或通过不受限接口暴露。巡检不得自动删除既有数据；后续清理继续遵守证据治理与显式确认规则。

#### Scenario: 执行巡检
- **WHEN** 系统记录私信、点赞或访客摘要
- **THEN** 数据只写入当前 RiskFlow 本地运行存储
- **AND** 不产生新的云模型请求或外部上传

### Requirement: 身份验证和登录异常失败关闭
巡检过程中出现登录页、身份安全验证、非目标前台应用或无法验证的隐私设置页面时，固定执行器 MUST 停止当前分区或任务，不得尝试登录、验证身份、修改隐私开关或继续盲目导航。

#### Scenario: 进入访客页要求开启记录
- **WHEN** 页面要求用户开启主页访客记录才能查看
- **THEN** 系统记录访客分区不可用并保持该开关不变
- **AND** 返回后继续其他安全的巡检分区或结束任务
