# 补齐互动巡检纠错证据与唯一发布身份

> 现行适用范围：见[上下文清理清单](../../../docs/context-cleanup.md#活动变更的适用范围)。本文件保留历次决策与未完成事实；退役聊天、旧详细巡检和旧初始化门槛不因本变更仍在列表而恢复。当前状态只读STATUS，勿以旧任务勾选推断本轮验收。

## Why

互动巡检会在内部把页面异常收口为 `failed` 或 `degraded`，但没有调用既有纠错记录入口，导致结果页只有事件文字，没有异常发生时的截图、UI结构和候选规则。与此同时，测试安装包必须使用递增版本和唯一提交，避免同号不同内容。

## What Changes

- 互动巡检复用视频流程的统一异常证据模块，在恢复页面之前保存最小截图和配对UI树。
- 致命失败、分区识别失败和恢复失败分别记录现场；明确不可用的账号入口不记程序故障。
- 公开接口只返回证据可用性和受限图片入口，不返回本机绝对路径或原始UI树。
- 无模型Key时保留证据且停止自动重试，配置后由用户显式重新加入只读分析队列。
- 本轮版本固定为 `0.4.1-dev.2`，由唯一干净提交、Git标签、发行清单和安装包哈希共同标识。

## Impact

- Affected specs: `correction-advisory`, `engagement-inspection`, `records-browser`, `windows-distribution`
- Affected code: 互动巡检、统一证据记录、只读分析器、记录接口、结果页、版本与发布流程
- Safety: 不新增设备动作，不重放任务，不改变既有任务终态
