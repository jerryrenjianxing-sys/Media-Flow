# MediaFlow 0.4.1-dev.2

这是内部测试预发布版本，重点补齐互动消息巡检的纠错证据闭环，并继续收敛标准化 MuMu 虚拟机池。

- 互动巡检发生页面或分区异常时，立即保存配对的异常截图与 UI 结构证据。
- 视频流程与互动巡检复用同一套纠错记录、只读分析和候选规则机制。
- 明确不可用的平台入口继续显示为“不可用”，不会误报为程序故障。
- 未配置模型时仍完整保存证据，配置后可由用户显式重试分析。
- 结果页和任务详情可查看异常现场、分析状态及候选规则；公开接口不泄露本机文件路径。
- 设备页默认采用标准化 MuMu 虚拟机池，真机入口可在设备设置中按需开启。

本版本不会自动执行或重放任何历史失败任务；安装或启动后任务队列保持原有暂停状态。
