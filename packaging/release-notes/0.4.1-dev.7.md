# MediaFlow 0.4.1-dev.7

- 自动发现并管理本机全部MuMu实例，包括默认实例和实例0。
- 只把实际900×1600、320 DPI作为整机业务环境标准；名称、Root、Android版本等改为信息或分项能力。

- ADB端口、Android身份、抖音小版本或MuMu安装位置变化后自动对账，并对受影响能力执行快速只读复验。
