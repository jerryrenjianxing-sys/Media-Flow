# MediaFlow 0.4.1-dev.44

未签名 Windows x64 开发测试版，不是稳定版。安装器、清单及 Git 标签绑定同一源码提交。

## 交付内容

- 当前外部 Agent＋MediaFlow Skill 首页与任务台，完整配置引导、主题定制、内容计划及结果查看。
- 自包含 Python、Node、ADB、控制组件、Windows 桌面壳和后台托管脚本。
- 沿用 dev.43 业务代码；修复安装版漏装角标数字字库，以及桌面壳仍打开退役端口的问题。
- 安装包不包含内嵌 OpenCode/Pi、巨大虚拟机镜像、个人模型 Key、业务数据库或设备原始截图。MuMu及目标应用需按Skill引导准备。

## 使用

下载 `MediaFlow-0.4.1-dev.44-Installer.exe`，核对配套 SHA-256 后安装。未签名程序可能被 Windows SmartScreen 提醒；先核对来源和哈希，不关闭系统保护。首次运行选择数据目录，在设置中配置自己的模型服务。

安装不代表启动设备任务；首页和任务台使用本机3001，业务API使用48138。更新前备份现有数据并停止正在执行的任务，不删除旧数据来升级。新电脑未做覆盖安装验收，建议先在测试电脑验证。
