# MediaFlow 0.4.1-dev.49：独立后台启动与本机接管修复

未签名Windows x64开发测试版，提供NSIS安装器与ZIP；保留现有Skill首页、任务台、业务接口及固定执行器，不含巨大虚拟机镜像，不内置聊天Agent。

- 修复Windows路径大小写造成的后台登记误判，按真实参数、运行时、脚本、工作目录及实例配置精确核对，不再用参数子串判断归属。
- 修复本机安装配置落入Codex MSIX私有映射、独立计划任务无法读取的启动失败。持久配置使用稳定外部数据根，生产登记拒绝依赖MSIX LocalCache的路径。
- 后台导入前建立UTF-8阶段与异常诊断；桌面区分登记缺失、任务禁用、提前退出、身份冲突、端口占用及超时，不显示乱码或原始PowerShell堆栈。
- 修复NSIS临时目录内原生System.dll与.NET动态编译引用冲突，辅助代码显式引用受信程序集；安装阶段结果另存持久日志，临时目录清理后仍可查。
- 安装与回退保存精确任务凭证，不覆盖其他程序登记；回退资料排除出源码、修复材料和安装载荷。保留既有任务、配置、凭据及历史证据，不恢复等待业务。

最终测试数量、本机启动/停止/再启动与历史回读范围见STATUS交付记录。此前dev.48的隔离通过不代替本机接管通过；实际关闭Codex后的独立运行及手机业务仍须单独验收。

发布使用唯一干净提交和纯版本标签，不覆盖旧版本；ZIP为安装器及校验材料合集，不是免安装版。MIT及全部第三方许可证随包保留。
